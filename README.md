# Бонус бағдарламасының Telegram-боты

Python 3.12, aiogram 3 және SQLite негізіндегі дайын жоба. Клиент пен әкімшіге арналған хабарламалар қазақ тілінде.

## Мүмкіндіктері

- `/start` пәрменімен тіркелу және Telegram ID сақтау.
- Бонустар балансын тексеру және жеке QR-код алу.
- Бір рет қолданылатын кодпен бонус есептеу.
- `/admin` әкімші панелі: бонус коды мен дүкен статистикасын басқару.
- Журнал жүргізу, қателерді өңдеу және транзакциялық қауіпсіз есептеу.

## Орнату және іске қосу

1. Python 3.12 орнатыңыз.
2. Виртуалды орта жасаңыз: `py -3.12 -m venv .venv`.
3. Оны іске қосыңыз: PowerShell-де `.\.venv\Scripts\Activate.ps1`, Linux/macOS жүйесінде `source .venv/bin/activate`.
4. Тәуелділіктерді орнатыңыз: `python -m pip install -r requirements.txt`.
5. `.env.example` файлын `.env` деп көшіріп, BotFather токенін және әкімшілердің сандық Telegram ID мәндерін енгізіңіз.
6. Ботты іске қосыңыз: `python bot.py`.

`.env` үлгісі:

```dotenv
BOT_TOKEN=BotFather_токені
ADMIN_IDS=123456789,987654321
DATABASE_PATH=data/bonus_bot.sqlite3
LOG_LEVEL=INFO
```

`data` бумасы мен SQLite файлы өздігінен жасалады. `.env` файлын жарияламаңыз.

Клиент QR-кодында `KURT-CUSTOMER:<Telegram ID>` мәтіні болады. Оны кассир немесе кассалық жүйе клиентті табу үшін оқи алады.
